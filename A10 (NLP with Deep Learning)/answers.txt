1.2 Reflection:
1. How do word embeddings like GloVe help in understanding relationships between words?

Word embeddings like GloVe turn words into numerical vectors, so words with similar meanings or related roles are placed close to each other in vector space. Because of this, the model can capture relationships such as gender, tense, comparison, or country-capital pairs. This helps computers work with meaning in a mathematical way instead of treating words as unrelated symbols.

2. Can you think of other applications where word vectors could be useful?

Word vectors could be useful in search engines, recommendation systems, chatbots, translation, sentiment analysis, and text classification. They are also helpful for finding similar documents, correcting spelling based on context, and improving question-answering systems.

2.4 Knowledge Check:
1. What are the strengths and weaknesses of using rule-based sentiment analysis compared to learned models like LSTM or RoBERTa?

Rule-based sentiment analysis like VADER is fast, simple, and does not need training data. However, it is weaker at understanding context, sarcasm, negation, and sentences written in different languages or unusual styles. Learned models like LSTM and RoBERTa can capture more complex patterns, but they require training data and more computation.

2. How does the attention mechanism in Transformers improve model performance?

The attention mechanism helps the model look at all important words in a sentence at the same time instead of only reading in order. This improves performance because the model can better understand context, long-range relationships, and which words matter most for the prediction.

4. What does GloVe use to represent word meaning?

GloVe represents word meaning using dense numerical vectors learned from word co-occurrence statistics in a large text corpus. Words that appear in similar contexts get similar vector representations.

5. Why does RoBERTa outperform LSTM in some cases?

RoBERTa can outperform LSTM because it is a pretrained transformer model with a stronger understanding of context and language patterns. Its attention mechanism helps it capture relationships between words more effectively, even when the wording is more complex.

6. How does padding affect model performance?

Padding is added so sentences in the same batch have the same length. If the model treats padding like real words, performance can get worse because it learns from meaningless tokens. That is why attention masks are important: they tell the model which tokens are real and which are only padding.
